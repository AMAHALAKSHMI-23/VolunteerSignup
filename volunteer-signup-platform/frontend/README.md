This volunteer web application allows user to
Register as volunteer abd admin ,and both having seperate profiles and seperate functionalities to opeate .
If u registered as volunteer then u can register for a event and u  will get notified through email.
If u registered as a dmin then u have access to create events which has specifications including date ,time,when it is going to happen and limit of the event along with location .
It is completely a MERN-full stack Role based  application which used
    **Mongodb
    **Express
    **React
    **Nodejs
